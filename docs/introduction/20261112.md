# 論文紹介

## Title
Evolution of altruistic rationality provides a solution to social dilemmas via rational reciprocity（利他的合理性の進化は、合理的互恵性を通じて社会的ジレンマに対する解決策をもたらす）

## Literature information
著者：Mohammad salahshour, Iadin D Couzin<br>
雑誌名：APS<br>
出版年：2025-09-02<br>
URL：https://link.aps.org/doi/10.1103/sz5b-j75y<br>

## はじめに
- 古典的なゲーム理論では、各エージェントが自分の利益だけを追求してナッシュ均衡に達し、共有地の悲劇（社会的ジレンマ）が結果として得られてしまう。
    - ナッシュ均衡：他のエージェントの戦略を考慮すると、どのエージェントも自分の戦略を変更しなくなる状態。
    - 社会的ジレンマ：個人にとっては合理的な行動を全員がとった結果、全員が協力した場合よりも社会にとって悪い結果を招いてしまう状況。
    - 共有地の悲劇：誰でも自由に利用できる共有資源を、各エージェントが自分の利益のために無限に利用した結果、資源が枯渇してしまう現象。
- しかし、生物界や社会生活においては協力が広く見られ、多細胞生物から社会構造に至るまで、あらゆる生命形態の礎となっている。
- そこで、進化ゲーム理論では、完璧な計算能力を前提とすることをやめ、「人間や動物の認識能力には限界があり、複雑な計算をして判断しているわけではない」という「限定合理性(Heuristicに行動選択)」の考え方を取り入れられた。
- その結果、社会的ジレンマを克服して協力が維持される様々な仕組みが解明された。
    - 血縁選択
    - 直接的・間接的互恵

- これまでは、
    - 「合理的に判断するプレイヤー＝自分の利益だけを追求する（利己的）」と決めらていた。
    - 行動のルールをあらかじめ個体にプログラムしていた。
    - ゲームの種類（囚人のジレンマ、スノードリフト、鹿狩りなど）によっては協力が維持できなくなったりする。
- 「合理性」と「利己性」を切り離して考え、合理的に判断するプレイヤーであっても、他者配慮を持ち得るのではないか。
