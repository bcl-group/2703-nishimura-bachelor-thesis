# 論文紹介

## Title
Evolution of altruistic rationality provides a solution to social dilemmas via rational reciprocity（利他的合理性の進化は、合理的互恵性を通じて社会的ジレンマに対する解決策をもたらす）

## Literature information
著者：Mohammad salahshour, Iadin D Couzin<br>
雑誌名：APS<br>
出版年：2025-09-02<br>
URL：https://link.aps.org/doi/10.1103/sz5b-j75y<br>

## Introduction
- 古典的なゲーム理論では、各エージェントが自分の利益だけを追求してナッシュ均衡に達し、共有地の悲劇（社会的ジレンマ）が結果として得られてしまう。
    - ナッシュ均衡：他のエージェントの戦略を考慮すると、どのエージェントも自分の戦略を変更しなくなる状態。
    - 社会的ジレンマ：個人にとっては合理的な行動を全員がとった結果、全員が協力した場合よりも社会にとって悪い結果を招いてしまう状況。
    - 共有地の悲劇：誰でも自由に利用できる共有資源を、各エージェントが自分の利益のために無限に利用した結果、資源が枯渇してしまう現象。
- しかし、生物界や社会生活においては協力が広く見られる。
- そこで、進化ゲーム理論では、完璧な計算能力を前提とすることをやめ、「人間や動物の認識能力には限界があり、複雑な計算をして判断しているわけではない」という「限定合理性(Heuristicに行動選択)」の考え方を取り入れられた。
- その結果、社会的ジレンマを克服して協力が維持される様々な仕組みが解明された。
    - 血縁選択
    - 直接的・間接的互恵
    - など

- これまでは、
    - 行動のルールをあらかじめ個体にプログラムしていた。
    - 「合理的に判断するプレイヤー＝自分の利益だけを追求する（利己的）」と決めらていた。

- 目的
    - 「合理性」と「利己性」を切り離して考え、合理的に判断するプレイヤーであっても、他者配慮を持ち得るプレイヤーとして自発的に利他行動が生まれるのかを解明する。

## The model and setup
- 対称2人2戦略ゲームをプレイするエージェントの集団を考察
- 各個体の主観的利得（subjective payoff）
    $$U_i^s(s_i, s_j) = (1 - \delta_i)U(s_i, s_j) + \delta_i U(s_j, s_i)$$
    - $s \in \{C, D\}$ ：戦略（「協力（cooperation）」と「裏切り（defection）」）
    - $\delta_i \in [0, 1]$：利他的性質
    - $U$：客観的利得関数
    - $s_i$ と $s_j$ ：個体 $i$ と個体 $j$ の戦略
- エージェントは合理的で、常に自身の主観的利得関数に基づいてプレイする。その結果、ゲームのナッシュ均衡（Nash equilibrium）に落ち着く。
- よく混ざった集団（well-mixed population）と構造化された集団（structured population）の双方における1回限りのゲームを検討し、個体は他者の利他性に関する完全情報を持っていると仮定する。

- ここでは、2人2戦略ゲームの各クラスに属する3つのゲームを研究する。
    - 純粋支配クラス（pure dominance class）に属する「囚人のジレンマ（Prisoner’s Dilemma）」
        - 協力へ誘導する力も、裏切りで罰する力も、どちらも一定の利他性（$>0$）がないと働かない。そのため、すべてのパーソナリティ（4タイプ）が存在し得る。
    - 反調整クラス（anticoordination class）に属する「雪かきゲーム（Snowdrift game）」
        - $\delta_D$ がマイナスになるため、「裏切りで罰する動機」が存在しない。プレイヤーは「無条件協力者」と「条件付き裏切り者」の2タイプのみに分類される
    - 調整クラス（coordination class）に属する「スタグハント・ゲーム（Stag Hunt game）」
        - $\delta_C$ がマイナスになるため、相手が協力するなら自分も常に協力したくなる。プレイヤーは「無条件協力者」と「条件付き協力者」の2タイプのみに分類される。
- これらのゲームは、４つの客観的利得パラメータによって定義される。 （図1(a)）
    - 相互協力の報酬（$R$：reward）
    - 相互裏切りの罰（$P$：punishment）
    - 相手が協力しているのに自分が裏切った際に得られる裏切りの誘惑（$T$：temptation）
    - 相手が裏切っているのに自分が協力した際に得られるお人好しの利得（$S$：sucker’s payoff）
    - $\delta_C = (T - R)/(T - S)$ 
    - $\delta_D = (P - S)/(T - S)$ 

- 個体は自身の客観的利得に比例する確率で繁殖する。
    - 子孫は親の利他的形質 $\delta$ を継承するが、突然変異の影響を受ける。
    - 突然変異率 $\nu$ で、一様ランダムに選ばれた $\delta \in [0, 1]$ の値を持つ子孫が生み出される。
