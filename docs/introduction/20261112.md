# 論文紹介

## Title
Evolution of altruistic rationality provides a solution to social dilemmas via rational reciprocity（利他的合理性の進化は、合理的互恵性を通じて社会的ジレンマに対する解決策をもたらす）

## Introduction
- 古典的なゲーム理論では、各エージェントが自分の利益だけを追求してナッシュ均衡に達し、社会的ジレンマが結果として得られてしまう。
    - ナッシュ均衡：他のエージェントの戦略を考慮すると、どのエージェントも自分の戦略を変更しなくなる状態。
    - 社会的ジレンマ：個人にとっては合理的な行動を全員がとった結果、全員が協力した場合よりも社会にとって悪い結果を招いてしまう状況。
- しかし、生物界や社会生活においては協力が広く見られる。
- そこで、進化ゲーム理論では、完璧な計算能力を前提とすることをやめ、「人間や動物の認識能力には限界があり、複雑な計算をして判断しているわけではない」という「限定合理性(Heuristicに行動選択)」の考え方を取り入れられた。
- その結果、社会的ジレンマを克服して協力が維持される様々な仕組みが解明された。
    - 血縁選択
    - 直接的・間接的互恵
    - など

- これまでは、
    - 「合理的に判断するプレイヤー＝自分の利益だけを追求する（利己的）」と決めらていた
    - 行動のルールをあらかじめ個体にプログラム
    - 過去の対戦履歴や評判システム、あるいは繰り返し対戦が不可欠
- 本実験では、
    - 個体が行動そのものを直接進化させるのではなく、相手の利益をどれくらい重視するかという「主観的な利得評価基準」そのものが進化
    - 自己組織的にエージェントの「条件付き協力者」などの戦略性質が発生・維持
    - 過去の履歴や将来の継続的な関係がない「一回限り（one-shot）」の対戦

- 目的
    - 「合理性」と「利己性」を切り離して考え、合理的に判断するプレイヤーであっても、他者配慮を持ち得るプレイヤーとして自発的に利他行動が生まれるのかを解明する。

## Agent-Based Simulation
1. 初期設定
    - 集団サイズ $N$（$N = 10000$）のエージェントを生成
    - 全エージェントの初期利他性パラメータを $\delta = 0$ に設定
2. 対戦相手の割り当て
    - ランダム混合集団：集団内のランダムに選ばれた相手と対戦
    - 空間格子集団：2次元の正方格子上に配置し、隣人4人と対戦
3. 意思決定と戦略の算出
    - 自分と相手の利他性（$\delta_i, \delta_j$）の情報から、相互作用時の主観的利得行列を計算
    - その主観的ゲームにおけるナッシュ均衡を数学的に計算し、その確率に従って「協力（C）」か「裏切り（D）」の戦略を決定
4. 客観的利得の獲得
    - お互いが出した戦略に対し、ゲームの客観的利得行列 $U'$（報酬 $R$, 試練 $P$, 誘誘 $T$, 愚か者の利得 $S$）に基づいて実際の獲得得点を計算
5. 複製・淘汰・世代交代
    - 各個体が獲得した客観的利得の大きさに比例した確率で、次世代に子孫を残す
    - 定員 $N$ を保つため、得点の低い個体や親世代が集団から押し出される形で淘汰（死亡）
6. 突然変異
    - 子孫生成時、確率 $\nu$（$\nu = 0.001$）で突然変異
    - 変異が起きた場合、子の利他性 $\delta$ を $[0, 1]$ の範囲から一様ランダムに再設定


## The model and setup
- 対称2人2戦略ゲームをプレイするエージェントの集団で考える
- エージェントは合理的で、常に自身の主観的利得関数に基づいてプレイする。その結果、ゲームのナッシュ均衡（Nash equilibrium）に落ち着く。
- 各個体の主観的利得関数（subjective payoff）
    $$U_i^s(s_i, s_j) = (1 - \delta_i)U(s_i, s_j) + \delta_i U(s_j, s_i)$$
    - $s \in \{C, D\}$ ：戦略（「協力（cooperation）」と「裏切り（defection）」）
    - $\delta_i \in [0, 1]$：利他的性質
    - $U$：客観的利得関数
    - $s_i$ と $s_j$ ：個体 $i$ と個体 $j$ の戦略
- 個体は他者の利他性に関する完全情報を持っていると仮定

- ゲームは、４つの客観的利得パラメータによって定義される。 [図1(a)]
    - 相互協力の報酬（$R$：reward）
    - 相互裏切りの罰（$P$：punishment）
    - 相手が協力しているのに自分が裏切った際に得られる裏切りの誘惑（$T$：temptation）
    - 相手が裏切っているのに自分が協力した際に得られるお人好しの利得（$S$：sucker’s payoff）
- ここでは、2人2戦略ゲームの各クラスに属する3つのゲームを研究する。[表1]
    - $\delta_C = (T - R)/(T - S)$ ：「相手が協力（$C$）しているとき、自分も裏切らずに協力（$C$）したくなる」ために必要な最低限の利他性
    - $\delta_D = (P - S)/(T - S)$ ：「相手が裏切り（$D$）を選んだとき、自分も裏切り（$D$）を返して罰を与える（お人好しになるのを避ける）」ための上限の利他性
    - 純粋支配クラス（pure dominance class）に属する「囚人のジレンマ（Prisoner’s Dilemma）」（$S < P < R < T$）
        - 協力へ誘導する力も、裏切りで罰する力も、どちらも一定の利他性（$>0$）がないと働かない。そのため、すべてのパーソナリティ（4タイプ）が存在し得る。
    - 反調整クラス（anticoordination class）に属する「雪かきゲーム（Snowdrift game）」（$P < S < R < T$）
        - $\delta_D$ がマイナスになるため、「裏切りで罰する動機」が存在しない。プレイヤーは「無条件協力者」と「条件付き裏切り者」の2タイプのみに分類される
    - 調整クラス（coordination class）に属する「スタグハント・ゲーム（Stag Hunt game）」（$S < P \le T < R$）
        - $\delta_C$ がマイナスになるため、相手が協力するなら自分も常に協力したくなる。プレイヤーは「無条件協力者」と「条件付き協力者」の2タイプのみに分類される。

- 個体は自身の客観的利得に比例する確率で繁殖する。
    - 子孫は親の利他的形質 $\delta$ を継承するが、突然変異の影響を受ける。
    - 突然変異率 $\nu$ で、一様ランダムに選ばれた $\delta \in [0, 1]$ の値を持つ子孫が生み出される。

## Result
1. Classification of personality types and games
    - 十分に混合された集団において、囚人のジレンマゲームをプレイする利己的合理主義者（$\delta_i = 0$）の集団を考える。
    - 予測
        - $0 < \delta_i$は個体の適応度を損なう。したがって、個体の利他性は増加せず、利己的合理主義者のままであるはず。
        - 囚人のジレンマのナッシュ均衡が相互裏切りであることを踏まえると、$R < T = 5$ の場合には悲劇が避けられず、この領域では協力は進化しないはず。
    - 結果
        - いづれも正しくない。
        - [図2(a)(b)]ナッシュ均衡は $R < 5$ で裏切りであるにもかかわらず、$R > 4$ で協力が進化することがわかった。
        - [図2(c)(d)]$\delta$ が高い個体は協力するし、$\delta$ が高いことはより多くの協力を受けることにもつながる。一方で $\delta$ が低い個体は裏切りを経験する。
        - 自己組織化された利己主義への罰を通じて、協力の進化が出現しうる。
2. Prisoner's Dilemma:Evolving cooperation through conditional cooperation
    - $0 < \delta_D < \delta_C < 1$となる領域では、協力者、裏切り者、条件付き裏切り者の3つのタイプのみが存在しうる。
    - $0 < \delta_C < \delta_D < 1$となる領域では、協力者、裏切り者、条件付協力者の3つのタイプのみが存在しうる。
    - [図1(b)]自分と対戦相手の利他性特性の値の関数として、各ゲームのナッシュ均衡における協力確率を色分けしてプロットしたもの。

    - [図3(c)(d)]十分に混合された集団および構造化された集団における、個体の利他特性の時間平均値の密度プロット

## Discussion
- 進化可能な他者配慮的選好（other-regarding preferences）を持つエージェントにおいて利得の主観的評価を許容することが、完全情報下での2人2戦略ゲームにおける協力の出現に対して統一的な説明を提供することを示した。
- 対戦相手の効用を含むように利得を歪める形質を組み込むことで、個体は利他主義者に選択的に報い、利己主義を罰するタイプを含む多様な戦略的性格タイプへと進化する。

- このアプローチは、戦略ではなく選好が進化する「間接的進化アプローチ（indirect evolutionary approach）」に分類される
- 個体は相手プレイヤーの利他性 $\delta$ を知っており、それによって条件付きで行動を調整することができる。
- モデルは直接互恵性や間接互恵性、あるいはパートナー選択といった既知のメカニズムと密接に関連しているが、協力を合理的な反応とする選好を進化させることで、一回限りの（one-shot）設定においてそれらを達成している。


## Materials and methods
1. The model and simulations
    - 戦略 $s \in C, D$ と利得行列 $U(s, s^*)$ を持つ対称な2人2戦略ゲームをプレイ
    - $s$ は注目する個体（focal individual）の戦略、$s^*$ はその対戦相手の戦略
    - 各個体 $i$ は利他性 $\delta_i$ を持ち、その主観的利得は自身の利得と相手の利得の加重和、すなわち $U_i^s = (1 - \delta_i)U + \delta_i U$

    - 各タイムステップにおいて、すべての個体がゲームをプレイして利得を獲得し、選択パラメータ $\beta = 0.5$ に自身の利得を掛けた値に比例する確率で繁殖
    - 個体の実際の利得は、ゲームの元の利得行列 $U$ に基づいて決定
    - 子孫は親の利他的形質を受け継ぐが、突然変異の対象となる。
    - 突然変異は確率 $\nu$ で発生し、その場合、子孫の利他的形質は $[0, 1]$ の範囲から一様ランダムに選ばれた値に設定
    - 利己的合理主義者（すなわち、すべての $i$ について $\delta_i = 0$）から開始

    - 十分に混合された集団（well-mixed population）と構造化された集団（structured population）の両方を検討
        - 十分に混合された集団：各タイムステップにおいて個体がランダムにペアを組んでゲームをプレイし、その後、すべての個体の戦略が同時に更新
        - 構造化された集団：個体は格子上に居住し、ネットワーク上のすべての隣接個体とゲームをプレイする。ゲームをプレイした後、個体は自身の拡張近傍内の個体の1人の戦略を、選択パラメータ $\beta = 0.5$にその利得を掛けた値の指数 $\exp(\beta \pi)$ に比例する確率で模倣する（このアルゴリズムは図5で Structured I ）
        - 個体の拡張近傍は、注目する個体とその隣接個体で構成
        - 集団ネットワークには、周期境界条件（トーラス構造）とフォン・ノイマン近傍（Von Neumann connectivity）を持つ最近接正方格子（first-nearest-neighbor square lattice）を用いる（斜めを含めた8近傍はムーア近傍（Moore neighborhood））
        - 図5では、個体が自身の利得に比例する確率で繁殖する代替的な進化ダイナミクス（Structured II と表記）も検討

    - 進化モデルには突然変異率 $\nu$ と集団サイズ $N$ という2つのパラメータしかない(本文では、$\nu = 10^{-3}$  $N = 10\,000$)
    - 集団サイズや突然変異率が小さいと...（モデルの信頼性のため）
        - 遺伝的浮動：集団の個体数が少なく、新たな突然変異がめったに起きない状況では、運や確率の偶然の影響が強く働く。その結果、集団全体がある特定のパーソナリティタイプ（例：完全な利己的個体や利他的個体）で一色に染まり、固定化する現象が起きやすくなる。
        - 断続的な波の発生：タイプがひとたび固定されると、しばらくはその状態が維持されるが、稀に発生した突然変異体をきっかけに、集団全体のタイプが一気に入れ替わる。 これにより、高い利他性と協力率が続く期間と低い利他性と協力率に落ち込む期間が、時間経過とともに交互に入れ替わるような断続的なサイクルが生じる
2. Boundedly rational agents in a structured population simulation(図5)
    - 主観的に合理的なエージェント：自身の主観的利得を計算する基準となる遺伝的な形質 $\delta$ を持っている
    - 限定合理的なエージェント：固定された遺伝的な戦略である協力 $C$ と裏切り $D$ を持っている

    - 各個体は、周期境界条件とフォン・ノイマン近傍を持つ最近接正方格子上に居住し、すべての隣接個体とゲームをプレイする。
    - ゲームをプレイした後、個体は自身の拡張近傍内の個体の1人の戦略を、選択パラメータ $\beta = 0.5$ にその利得を掛けた値に比例する確率で模倣する。(Structured I )
    - 個体が自身の利得に比例する確率で繁殖する（Structured II）
    - 個体の拡張近傍は、注目する個体とその隣接個体で構成

    - 主観的に合理的なエージェント：対戦相手の利他性を知っている
    - 限定合理的なエージェント：対戦相手の利他性をしらない

3. The game structures
    1. Prisoner's Dilemma
        - $S < P < R < T$ 
        - 相互協力が最大の総利得をもたらす。
        - しかし、各プレイヤーは裏切りによって自身の利得を増やすことができる。その結果、ゲームのナッシュ均衡は相互裏切りとなり、すべてのプレイヤーが協力した場合よりも悪い状態に陥る。
        - 純粋に合理的なエージェント間でこのゲームがプレイされる際には避けられない。
        - 基本パラメータ値は $T = 5$、$S = 0$、および $P = 1$ であり、$R$ を1から5の間で変化させた。
    2. Snowdrift game
        - $P < S < R < T$
        - 相手が協力する場合、裏切りは協力よりも高い利得をもたらす。したがって、裏切りへの誘惑が存在する。
        - しかし、相互裏切りは最小の利得をもたらす。その結果、ナッシュ均衡は個体が裏切りと協力で反協調する異質な戦略ペアとなる。
        - 混合戦略ナッシュ均衡を許容する。したがって、ナッシュ均衡において次善の協力が観察されるため、このゲームは弱い社会的ジレンマのみを提供する。
        - 基本パラメータ値は $T = 5$、$S = 1$、および $P = 0$ であり、$R$ を1から5の間で変化させた。
    3. Stag Hunt game
        - $S < P \le T < R$
        - このゲームには2つの純粋戦略ナッシュ均衡が存在する。
            - 相互協力はより高い利得をもたらす社会的に最適な結果
            - 相互裏切りはより低い結果をもたらすもののリスク支配的なナッシュ均衡
            - 混合戦略ナッシュ均衡を許容する。
            - 基本パラメータ値は $R = 3$、$P = 1$、$S = 0$ であり、$T$ を1から5の間で変化させた。
            - $R > 3$の場合、このゲームは囚人のジレンマになる

4. The relation with standard classes of two-person two-strategy games
    - 利己的合理主義者は、上記2つの差分（$T - R$ と $P - S$）の正負によって、ゲームが以下の3つのクラスに綺麗に分かれます。
    1. 純粋支配クラス（Pure dominance class）
        - 条件: $T - R \ge 0$ かつ $P - S \ge 0$
        - 特徴: どんなときも裏切るのが一番得になる構造
        - ナッシュ均衡: 「相互裏切り」のみ（例：囚人のジレンマ）
    2. 反協調クラス（Anticoordination class）
        - 条件: $P - S < 0 < T - R$
        - 特徴: 相手と「逆の手」を出すのが一番マシになる構造
        - ナッシュ均衡: 「一方が協力、もう一方が裏切り」の不一致ペア、および確率で手を混ぜる混合戦略（例：スノードリフトゲーム）
    3. 協調クラス（Coordination class）
        - 条件: $T - R < 0 < P - S$
        - 特徴: 相手と「同じ手」を出すのが得になる構造
        - ナッシュ均衡: 「相互協力」と「相互裏切り」の2つの選択肢、および混合戦略（例：鹿狩りゲーム）

5. The mixed strategy Nash equilibrium
    - 混合戦略：どの手をどれくらいの確率で出すかのリスト
    - 混合戦略のサポート（support）：選択肢として実際に残っている手だけを集めたセット
    - 混合戦略ナッシュ均衡：各戦略が他方の戦略に対する最適反応（best response）となる2つの混合戦略の組 $(q_i, q_j)$、すなわち $q_i = BR(q_j)$ かつ $q_j = BR(q_i)$ として定義される
        - 条件
            - 混合戦略のサポート内にあるすべての戦略の利得が等しい
            - サポート外の他のどの戦略もその混合戦略に対してより高い利得を与えない
    - 混合戦略の計算
        - プレイヤー $i$ が確率 $q_i(C)$ で戦略 $C$ をプレイし、確率 $q_i(D) = 1 - q_i(C)$ で $D$ をプレイすると仮定する。
        - プレイヤー $j$ が $C$ をプレイすることで得られる期待利得は $q_i(C)R_j^s + (1 - q_i(C))S_j^s$ 
        - $D$ をプレイすることで得られる期待利得は $q_i(C)T_j^s + (1 - q_i(C))P_j^s$ 
        - これら2つを等しいとおくと、プレイヤー $i$ の混合戦略ナッシュ均衡として $q_i^*(C) = (P_j^s - S_j^s)/(R_j^s + P^s - T_j^s - S_j^s)$
        - 上付き文字 $s$ は主観的利得を指し、$R_j^s = R$、$P_j^s = P$、$S_j^s = (1 - \delta_j)S + \delta_j T$、および $T_j^s = (1 - \delta_j)T + \delta_j S$ 
        - 同様に、プレイヤー $j$ のナッシュ均衡混合戦略は $q_j^*(C) = (P_i^s - S_i^s)/(R_i^s + P^s - T_i^s - S_i^s)$
        - 自身の価値観を変えることで、他者の行動を変えることができる
    
    6. Replicator-mutator dynamics
    - 連続値
        - レプリケーター・ミューテーター方程式は、異なる値の利他的形質を持つ個体の密度 $\rho_t(\delta)$ の時間発展を支配
            - $$\rho_{t+1}(\delta) = \int_0^1 W(\delta, \delta') \rho_t(\delta') \frac{\pi_t(\delta')}{\overline{\pi_t}} d\delta' $$
        - $\pi_t(\delta)$ は時刻 $t$ における利他性 $\delta$ を持つ個体の期待利得
        - $\overline{\pi_t} = \int_{\delta=0}^{\delta=1} \pi_t(\delta)\rho_t(\delta)d\delta$ は時刻 $t$ における集団の平均利得
        - $W(\delta, \delta')$ は利他性 $\delta'$ から利他性 $\delta$ への突然変異率
            - 一様突然変異の仮定の下では、 $W(\delta, \delta') = \nu + (1 - \nu)\Delta(\delta - \delta')$ 

        - $$\pi_t(\delta) = \int_0^1 \rho_t(\delta') q^*(\delta, \delta') U' q^{*t}(\delta', \delta) d\delta' $$
        - $U'$ はゲームの（客観的な）実効利得行列である。本文で検討したモデルでは、個体は選択パラメータに自身の利得を掛けた値に比例する確率で繁殖するため、$U' = \exp(\beta U)$ 
        - 個体が自身の利得に比例する確率で繁殖する場合、$U' = U$ 
        - $q^*(\delta, \delta')$ は、利他性 $\delta$ を持つ主観的に合理的なエージェントが、利他性 $\delta'$ を持つエージェントとゲームをプレイする際の混合戦略ナッシュ均衡
        - 2人2戦略ゲームでは、これらはベクトル $q^* = [q_C^* \quad q_D^*]$ 
        - 集団の平均利得は
            - $$\overline{\pi_t} = \int_0^1 \pi_t(\delta) \rho_t(\delta) d\delta $$
        
    - 離散値へ
        - $$\rho_{t+1}(\delta_k) = \sum_{k'=1}^n \left[ \Delta_{k, k'}(1 - \nu) + \frac{\nu}{n} \right] \rho_t(\delta_{k'}) \frac{\pi_t(\delta_{k'})}{\overline{\pi}} $$
            - $k \in [1, n]$ であり、$n$ は利他的形質の可能な値の数を表す。妥当な選択として、数値解では区間 $[0, 1]$ において線形に等間隔な利他的形質の値を用いる。
            - $\Delta_{k, k'}$ はクロネッカーのデルタ関数を示し、$\delta = \delta'$の場合は1に等しく、それ以外の場合は0となる。利他性 $\delta_k$ を持つ個体の利得は
        - $$\pi_t(\delta_k) = \sum_{k'=1}^n \rho_t(\delta_{k'}) q^*(\delta_k, \delta_{k'}) U q^{*t}(\delta_{k'}, \delta_k) $$
        - 平均利得は
            - $$\overline{\pi_t} = \sum_{k'=1}^n \pi_t(\delta_{k'}) \rho_t(\delta_{k'}) $$
        - $n = 400$ に対するレプリケーターダイナミクスの数値解は図3(e)、3(f)、および図5に示されており、シミュレーション結果と高い一致を示している。
        - レプリケーターダイナミクスで得られる利得は、混合戦略ナッシュ均衡の期待利得
